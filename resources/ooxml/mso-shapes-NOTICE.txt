mso-shapes.json — Office's built-in shape definitions for legacy PowerPoint (.ppt) files

The vertices, segments, formulas, text rectangles, default adjust values and the
default fill/stroke tables in mso-shapes.json are extracted, unchanged in meaning,
from LibreOffice's svx/source/customshapes/EnhancedCustomShapeGeometry.cxx:

  https://git.libreoffice.org/core/+/refs/heads/master/svx/source/customshapes/EnhancedCustomShapeGeometry.cxx

That file is licensed under the Mozilla Public License, v. 2.0
(https://mozilla.org/MPL/2.0/), which allows it to be combined with Lumina Live
under the GNU GPL v3 or later (MPL-2.0, section 3.3). The source of the extracted
data is the file above.

To regenerate it from a LibreOffice checkout:

  python3 -I scripts/extract-mso-shapes.py \
    svx/source/customshapes/EnhancedCustomShapeGeometry.cxx include/svx/msdffdef.hxx \
    resources/ooxml/mso-shapes.json
