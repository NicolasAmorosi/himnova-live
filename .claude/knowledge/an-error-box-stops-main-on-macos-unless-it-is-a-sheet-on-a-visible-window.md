## An error box stops main on macOS unless it is a sheet on a visible window, and the async API does not change that
**Area:** main process
**Trigger:** showing any dialog from main (`dialog.showErrorBox`, `dialog.showMessageBox`, `reportCrash` in `main/index.ts`), above all one that can appear mid-service

- **Measured 2026-11-15 (audit probes `sonda-errorbox`, `sonda-messagebox`, Electron 44 on an M3):** from the moment `showErrorBox` opens until somebody clicks, main serves nothing: 0 timer ticks and 0 IPC. GO LIVE, NEGRO and LOGO are IPC, and the engine's frames and the NDI output's paints go through main, so the picture freezes while the engine's sound goes on.
- **`showMessageBox` without a parent is no better on macOS**, although it returns a promise: with no visible parent Electron runs it with `runModal`, and the call does not even return (0 ticks, 0 IPC).
- **With the visible control window as parent it is a sheet, and main keeps running:** 64 ticks and 75 IPC in 3.8 s, one pause of ~0.4 s as the sheet opens. A hidden or minimized parent falls back to the blocking box. Windows (where the async box runs on another thread) was not measured.
- **Linux (measured 2026-11-18, the Linux PC: GNOME over XWayland, the package):** the same `showMessageBox(parent)` is a separate «Error inesperado» window (`wmctrl -l` lists it), and main answers each IPC in 8 to 17 ms while it is up; a minimized control window is restored and visible. Both E2E pass there. The visible case runs on Linux; the minimized one stays macOS only until it has been run in the Docker setup the Linux suite also uses.
- **What the app does since (audit A23):** `reportCrash` shows a sheet on the control window whenever it is alive, and `showErrorBox` only when there is none (a failed start, or closed on macOS). Minimized (the operator may minimize it mid-service with the projector up, owner 2026-11-13) or hidden, it is restored or shown first, and the sheet waits until `isVisible()` says so, because the restore is animated: a minimized window fell back to the blocking box (review of A23, 2026-11-16). The projector window is never touched. E2E: `robustness.spec.ts`, «an uncaught error in main is said in a box that leaves main serving the control window» and «with the control window minimized, an uncaught error in main brings it back and still leaves main serving» (without the follow-up: «main is held», and the app does not exit on `app.exit(0)`).
